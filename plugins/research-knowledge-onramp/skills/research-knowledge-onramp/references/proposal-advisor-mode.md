# Proposal Advisor Mode

Use this mode when the user has a direction, a rough idea, or a thesis interest and needs help turning it into a researchable project.

## Proposal questions

1. What is the smallest precise question we can test?
2. What is the gap relative to current methods?
3. What is the minimum viable baseline set?
4. What data or evidence will make the claim believable?
5. What metric will decide whether the idea worked?
6. What failure mode would kill the proposal early?

## Standard proposal starter pack

- topic and motivation
- gap statement
- research question
- hypothesis
- technical route
- baselines
- metrics
- feasibility risks
- expected contribution
- near-term action plan

## Healthy proposal rules

- make the question narrower before making it grander
- prefer one testable contribution over three vague contributions
- separate engineering work from scientific claim
- name the strongest baseline before claiming originality
