# Coursework Mode

Use this mode when the user wants exam prep, chapter review, or a study pack.

## Default output order

1. Course main line
2. Chapter or topic summaries
3. Core formulas and meaning of variables
4. Common question types
5. Calculation templates
6. Memorization or speed-review version

## For every chapter

- Explain what problem this chapter solves
- Give a short intuitive explanation first
- Then give the formal definition or formula
- Then explain what the teacher is likely to ask
- End with common mistakes and a memory cue

## For calculations

Use the same pattern every time:

1. Identify the topic
2. Write the formula
3. Define variables
4. Substitute values
5. Interpret the result

## If the user is a beginner

Add:

- whiteboard-style explanation
- why this matters
- what to memorize now
- what can wait
