# Paper Mentor Mode

Use this mode when the user gives a paper and wants guidance that feels like a supervisor discussion rather than a summary.

## Default reading questions

1. What problem is the paper really trying to solve?
2. What is actually new relative to the obvious baselines?
3. Which claims are strongly supported, and which are only suggested?
4. What assumptions does the method quietly rely on?
5. What would break if the data, task, or evaluation changed?
6. What is the next paper or experiment to read?

## Standard paper mentor brief

- problem framing
- core claim
- novelty relative to prior work
- method sketch
- evidence and experiments
- hidden assumptions
- strongest limitation
- reproducibility notes
- follow-up directions

## Critique stance

- do not confuse performance gain with conceptual novelty
- do not repeat the abstract as critique
- ask which baselines are missing
- ask whether the metric really measures the claimed improvement
- ask whether the conclusion depends on one narrow setup
