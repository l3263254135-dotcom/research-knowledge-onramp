# Source Intake and Priority

Use the user's materials in this order:

1. Local PPTs, PDFs, notes, and handouts
2. Local textbooks or book excerpts
3. Local papers, reports, or code
4. User-provided web links
5. External sources only when the local material is incomplete

## What to extract

- chapter or section structure
- teacher wording or task wording
- formulas and variable definitions
- examples and worked problems
- repeated keywords and exam or research emphasis

## What to preserve

- original terminology when it is course-specific
- file names and chapter numbers when they matter
- the user's request for "not deleting" or "append only"

## What to flag

- missing prerequisites
- inconsistent chapter systems
- unsupported claims
- places where the source is only suggestive, not explicit
